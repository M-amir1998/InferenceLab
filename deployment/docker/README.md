# GPU engine containers

Reference Compose files for running the serving engines **on a GPU host**. They mirror
the commands generated by `inferencelab backend launch-plan` for the deployments in
`configs/deployments/` and are pinned to the versions the launch builders were checked
against on 2026-11-13:

| Engine | Image | Notes |
|---|---|---|
| vLLM | `vllm/vllm-openai:v0.33.0@sha256:d825baf9…` | entrypoint is `vllm serve`; CUDA 13 (driver R580+) |
| SGLang | `lmsysorg/sglang:v0.5.23@sha256:f832b5c3…` | no entrypoint (`sglang serve …`); CUDA 13 |
| TensorRT-LLM | `nvcr.io/nvidia/tensorrt-llm/release:1.2.1` | `--ipc=host` + memlock/stack ulimits required |

All ports are published on `127.0.0.1` only. Benchmarks run on the same host (see
`inferencelab remote run`), so no engine endpoint is exposed to the internet. Secrets such
as `HF_TOKEN` live in `~/.inferencelab/env` on the host (created by
`scripts/remote/bootstrap.sh`) — never in these files.

The CPU-only gateway image is the repository's root `Dockerfile`; it never contains CUDA.
