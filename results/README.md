# results/

Benchmark run directories (`results/<run-id>/`) are written here by
`inferencelab benchmark run`, `inferencelab experiment run` and `inferencelab demo`.

Everything in this directory except this README is **git-ignored**: run directories contain
request-level data (`requests.parquet`) and are regenerated on demand. Curated,
human-readable reports that are worth keeping go to `reports/` instead.
